Bibleverse

A web and command-line tool that suggests Bible verses based on feeling

github.com ↗

Bibleverse is a command-line and web tool that helps you find the Bible verses that speak most to your circumstance.

Religious people, and most especially Christians, find solace in the written word about their faith. The Bible contains 66 books and many verses that talk about different things and circumstances. This tool is geared towards helping Christians find relevant verses directed towards their condition.

Getting started

  1. Create a virtual environment
   python -m venv .venv
  1. Activate it
   source .venv/bin/activate
  1. Clone the repo
   git clone https://github.com/ajalamarvellous/bibleverse.git
  1. Install the packages
   pip install -r requirements.txt

Usage

python src/cli.py          # command line
streamlit run src/web.py   # web service
