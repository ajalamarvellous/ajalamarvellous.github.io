DL-Framework

A numpy-based deep learning framework

github.com ↗

DL Framework is an educational library implementing core deep learning concepts using just numpy.

It is not a replacement for PyTorch, TensorFlow or Keras, but educational content that shows how deep learning concepts are implemented, with an API similar to Keras.

Implemented:

  • ✓ Feed-forward propagation
  • ✓ Back propagation
  • ✓ Convolution layer
  • ○ RNN layer
  • ○ GNN layer
  • ○ Transformer block
  • ✓ Activation layer — ReLU, Sigmoid, Tanh
  • ✓ Training interface
  • ✓ Dropout layer
  • ✓ Early stopping
  • ✓ Gradient descent
